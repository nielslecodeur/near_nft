# Everkeep — test-receiver

Receiver adversarial pour les tests sandbox uniquement : accepte ou retourne le NFT et tente un retrait signé pendant la propriété temporaire. Non déployé par le script testnet.

Build et tests depuis la racine du monorepo : `bash scripts/build.sh`, `bash scripts/test-contracts.sh`, `bash scripts/demo.sh`.

Voir le [README général](../../README.md) et le [modèle de menace](../../docs/threat-model.md).
