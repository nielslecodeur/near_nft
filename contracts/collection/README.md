# Everkeep — collection

Factory de wallets nommés sans clé et index NFT synchronisé. Le build embarque artifacts/wallet.wasm : compiler le wallet en premier.

Build et tests depuis la racine du monorepo : `bash scripts/build.sh`, `bash scripts/test-contracts.sh`, `bash scripts/demo.sh`.

Voir le [README général](../../docs/everkeep/README.md) et le [modèle de menace](../../docs/threat-model.md).
